# BTC Race 24h Entry

This bot trades CBBTC against USDC using one-minute closes: it buys with available cash when 24-bar momentum is positive or when price is at least 0.5% below its 20-bar average and the five-bar decline has stabilized. It exits the full position at a 2% gain or 0.6% loss, waits 24 bars after a sale before re-entering, and makes one fallback purchase after bar 1300 if no order has filled. Every order uses a 100 bps slippage limit.
